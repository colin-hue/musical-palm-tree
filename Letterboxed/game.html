How to Play & Scraper Info

Official Rules:

  • Connect letters around the box to form words.
  • Words must be at least 3 letters long.
  • Consecutive letters cannot come from the same side of the square.
  • The last letter of a word becomes the first letter of the next word.
  • Goal: Use all 12 unique letters in as few words as possible!

Scraper & CORS Options:

This app automatically requests daily puzzle data from: https://letterboxedanswers.com/letter-boxed-{month}-{day}-{year}-answers/

Because browsers block cross-origin requests (`file://` or distinct domains), the app cycles through public CORS proxies:

  • api.allorigins.win
  • corsproxy.io
  • api.codetabs.com

Local Usage / CORS Troubleshooting:

If running locally via file:// and proxy services are offline or rate-limited:

  1. Use the built-in "Preset / Edit" button to load historical daily puzzles or type any custom letters.
  2. Launch your local browser with CORS disabled, or use a local HTTP server with CORS enabled.
